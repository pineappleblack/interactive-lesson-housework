# Кто больше занимается домашними делами

Самостоятельная интерактивная страница для GitHub Pages. Откройте `index.html` в браузере: сервер и сборка не нужны.

- Девочка 10–11 лет: 387,6 минуты в неделю, 6,5 часа в подписи, 78 шариков по 5 минут.
- Папа ребёнка до 7 лет: 218,8 минуты в неделю, 3,6 часа в подписи, 44 шарика по 5 минут.
- Ползунок: 0–12 часов, шаг 10 минут.

Источник: Росстат, выборочное наблюдение использования суточного фонда времени населением, таблица 2.4. Число шариков округлено по исходным минутам, а не по часам в подписи.

Анимация использует Matter.js для физики и D3 Selection для точек в SVG. Лицензии библиотек находятся в `assets/`.
